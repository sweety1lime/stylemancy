## Решения (согласовано 13.10.2026)

- **Аудитория:** подростки 14–18 лет; тренажёр нужен и на уроке, и дома.
- **Формат:** сюжетный квест в фэнтези-мире, где CSS — это магия. Внутри каждого задания — головоломка с настоящим CSS.
- **Главы = темы курса:** HTML (теги, семантика), селекторы и каскад, блочная модель, Flexbox/Grid/адаптив. Первой делаем Flexbox/Grid/адаптив — группа проходит её сейчас.
- **Аккаунты:** код класса + ник + пароль (без почты), панель учителя.
- **Мотивация:** звёзды, XP, достижения. Рейтинг группы и соревнования на уроке не нужны.
- **Стек:** React + TypeScript + Vite, сервер — Supabase.
- **Выпуск:** первая версия сразу вместе с аккаунтами и панелью учителя.

## Решения по квесту (13.10.2026)

- **Стиль:** пиксель-арт, палитра «ночная магия». Вся графика рисуется в коде (пиксельные SVG), без внешних картинок. Пиксельный шрифт — в заголовках и кнопках; длинные тексты и код — обычным шрифтом, чтобы легко читались.
- **Навигация:** карта королевства (районы-темы) → тропа уровней района → уровень.
- **Персонажи:** пиксельные портреты-эмблемы в SVG (наставники районов, Лорд Дефолт).
- **Ранги за XP:** Искра → Звезда → Созвездие → Сверхновая (слова без рода).
- **Гримуар:** справочник заклинаний + живые примеры, повторение пройденного, шпаргалка для печати, заметки студента.
- **Достижения:** за чистоту, за упорство, за исследование, секретные.
- **Сюжет:** реплики перед уровнями + сценка-вступление (3–4 кадра) и победная сцена у каждого района.

## Концепция

Королевство Каскадия держится на Магии Стилей. Лорд Дефолт хочет вернуть миру стили браузера по умолчанию — Times New Roman и синие подчёркнутые ссылки — и наложил проклятие. Игрок — ученик Академии Каскада: восстанавливает земли, осваивая заклинания.

- **Магия — только обёртка.** Заклинания — настоящие CSS-свойства с настоящими названиями. Под репликой персонажа всегда есть задача простым техническим языком.
- **Гримуар** — личный справочник: каждое освоенное свойство записывается туда с объяснением и примером.

## Сквозной сюжет

- **Пролог игры «Великий Сброс»** показывается один раз на карте: Лорд Дефолт проклял все земли разом, Академия Каскада отправляет героя. С какой земли начать — решает учитель.
- **Земли — главы** в порядке курса: Долина Тегов → Лес Селекторов → Крепость Блоков → Парящие земли. Сюжет подстраивается под любой порядок: сценки помнят, какие земли уже спасены (условия у кадров: первая глава, «уже спасена такая-то земля», «спасено всё»).
- **Лорд Дефолт помнит героя:** при первой встрече — «Ученик Академии? Ха!», потом — «Опять ты, {ник}!». Наставники встречают: «Слава о тебе дошла и до нас».
- **Финал земли:** наставник вручает руну (Руна Тегов, Руна Раскладки…), Лорд Дефолт сбегает туда, где проклятие ещё держится, а наставник отправляет к следующей открытой земле.
- **Цитадель — финальная битва.** Общий финал — когда спасены все четыре земли: Лорд Дефолт не сдаётся, а сбегает за дверь `<script>`, туда, где страницы оживают; герой получает звание Магистра Стилемантии, а наставник говорит, что догнать злодея поможет только новая магия — JavaScript. Продолжение — главы по JS.
- **Летопись героя** — все сценки по главам и грамоты для печати. Учителю открыто всё, включая финал.

## Как проходит уровень

1. Точка на карте → 2–3 реплики персонажа → чёткая формулировка задачи.
2. Слева редактор CSS, справа сцена: предметы и светящиеся контуры целей.
3. Сцена обновляется при каждом нажатии клавиши; опечатки подчёркиваются сразу: «`centre` — может, `center`?»
4. «Сотворить» (Ctrl+Enter) проверяет результат и объясняет по каждому предмету: «Рубин: нужно на 40px правее».
5. Победа: звёзды (3 — без подсказок и лишних свойств), XP, запись в гримуаре.

Подсказки — три ступени: идея → свойство → почти ответ. Снижают звёзды, но не блокируют прохождение.

## Устройство

**Проверка — сердце движка** (`src/engine`):
- код студента рендерится в изолированном iframe, рядом в скрытом — эталонное решение;
- сравниваются положение и размер предметов (допуск 2px); контуры целей берутся из эталона;
- собственный разбор CSS находит то, что браузер выбрасывает молча: опечатки в свойствах и значениях, пропущенные `;` и `}`, селекторы, которые ничего не находят;
- в районе действует список разрешённых свойств: на островах — только Flexbox, чтобы задачу не обходили через `margin` или `position`;
- адаптив проверяется в нескольких «зеркалах»: сцена рендерится на каждой ширине экрана, промахи называются по зеркалам;
- уровень может требовать приём (`require`): про `fr` или `repeat()` нельзя пройти пикселями;
- медиазапрос с ошибкой браузер молча не применяет — движок это замечает и объясняет («не хватает двоеточия», «нет единиц»).

**Уровень — файл с данными** (`src/levels/<район>/`): реплики, задача, HTML сцены, стартовый код, эталон, подсказки.

**Стек:** React + TypeScript + Vite, CodeMirror 6; Supabase (этап 3); GitHub Pages; Playwright.

**Тесты:** `npm test` в настоящем браузере проверяет, что эталон каждого уровня проходит, а стартовый код — нет, и прогоняет сценарии игрока.

## Часть II: Скриптория (JavaScript)

Курс JS начинается с основ языка (переменные, типы, условия, циклы, функции, массивы — в консоли и через `alert`/`prompt`), DOM и события — во второй половине. Главы = темы курса, как в Каскадии.

**Сюжет.** За дверью `<script>` — Скриптория: страна, где всё движется само — шестерёнки, механизмы, живые страницы. Здесь заклинания — не описания, а приказы: CSS говорит, как всё выглядит, JavaScript — что делать и когда. Лорд Дефолт хочет всё обнулить: колбы пусты (`undefined`), Оракул молчит, кнопки ничего не делают, а формы перезагружают страницу — «как положено по умолчанию». Его подручные — Призрак Андефайнд (пустые колбы), шут NaN (не-число) и баги-жуки (ошибки в коде). Последнее заклинание игры — `event.preventDefault()`: буквально «запретить Дефолт».

**Переход из Каскадии — плавный:**
- намёки по пути: в Кузнице Форм кнопка «нажмёшь — а сама ничего не сделает», на Грибных полянах `:hover` «не помнит прикосновения» — оживить и запомнить умеет только магия за дверью `<script>`;
- в углу карты Каскадии с самого начала стоит запертая дверь `<script>`, тропа от Парящих земель ведёт к ней;
- дверь открывается, когда учитель откроет классу землю Скриптории **или** когда герой спасёт все четыре земли — что раньше. Гостю и учителю она открыта сразу;
- общий финал отправляет к двери, а пролог Скриптории знает, видел ли герой финал: «ты шагнул следом за Лордом Дефолтом» или «Академия получила тревожную весть — земли Каскадии подождут»;
- у Скриптории своя карта, дверь на ней ведёт обратно в Каскадию.

**Земли Скриптории** — в порядке курса:

| Земля | Тема | Районы | Механика |
|---|---|---|---|
| Врата Скриптории | Вывод, переменные, типы, операторы, ввод | Зал Оракула (console.log, числа и строки, let, присваивание, const, имена, операторы), Лавка Алхимика (строки и шаблоны, typeof, преобразование типов, prompt и alert) | Оракул и колбы |
| Лабиринт Решений | Условия и циклы | Развилки (if/else, сравнения, логические операторы), Карусель Циклопа (while, for, break), Сердце лабиринта (испытание) | Путь героя |
| Мастерская Рецептов | Функции, массивы, объекты | Котёл Функций, Обоз (массивы), Картотека (объекты) | Алхимия функций |
| Город Механизмов | Страница и события | Мастерская Квери (DOM), Рычаги и шестерни (события), Мастерская игр, Логово Лорда Дефолта (финал) | Оживление и механизмы, Мастерская игр |

Наставники — тоже игра слов: Оракул Консоль (`console`), Алхимик Тайпоф (`typeof`), Страж Иф (`if`), Циклоп Фор (`for`, циклоп — от «цикла»). Остальных назовём, когда дойдём до их земель.

**Игры-механики** (выбраны 15.10.2026):
1. **Оракул и колбы** — основы. Код выполняется по-настоящему. Свиток Оракула показывает всё, что выведено через `console.log`, а переменные стоят на полке колбами: имя на этикетке, цвет жидкости — тип (число — синий, строка — зелёный, логическое — золотой, пустая колба — `undefined`). Видно, почему `'5' + 3` даёт `'53'`, а не `8`. Цели — нужные строки и значения колб — строятся из эталона, как контуры в CSS-уровнях. **Гости лавки:** код запускается несколько раз с разными ответами на `prompt` — как «зеркала» в адаптиве — и должен работать для каждого гостя.
2. **Путь героя** — условия, циклы, функции. Наш герой идёт по подземелью по приказам `hero.step()`, `hero.turnLeft()`, `hero.take()`, `hero.isWall()`. Код проверяется сразу на нескольких подземельях разной длины и формы, поэтому заучить маршрут не выйдет — нужен алгоритм. Звезда за краткость («уложись в 6 строк») подталкивает к циклу.
3. **Алхимия функций** — функции, массивы, объекты. Студент пишет функцию-рецепт, по конвейеру едут флаконы-тесты и загораются зелёным или красным: «для 3 и 5 ждали 8, а вышло '35'». Массивы — обозы с вагонами, пронумерованными с нуля; `map` — перегонка, `filter` — сито.
4. **Оживление и механизмы** — DOM и события. Пиксельные сцены, как в Каскадии, но меняет их JS: найти элемент (селекторы из Леса Селекторов работают и здесь!), зажечь фонарь через `classList.add`, написать на табличке через `textContent`, повесить событие на рычаг. Проверка проигрывает сценарий: «нажали рычаг → ворота открыты → нажали ещё раз → закрыты».
5. **Мастерская игр** — финал. По шагам собирается настоящая мини-игра: кликер кристаллов, «Угадай число у Сфинкса», мемори из рун. Каждый уровень добавляет одну возможность, а готовую игру можно скачать HTML-файлом — показать друзьям и родителям.
6. **Охота на баги** — внутри каждой земли: Лорд Дефолт запускает в рабочий скрипт жуков-багов, а студент находит и чинит ошибки — как починка разметки в Долине Тегов.

**Движок JS-уровней:**
- код студента выполняется в отдельном фоновом потоке (Web Worker), а не на странице игры: он не видит ни игру, ни прогресс, ни аккаунт. Зависший цикл останавливается через пару секунд с пояснением «похоже на бесконечный цикл»;
- код выполняется как настоящий `<script>`: переменные верхнего уровня — это и есть колбы на полке;
- свой разбор кода (парсер acorn) объясняет ошибки по-русски ещё до запуска: незакрытые кавычки и скобки, «ёлочки» и “лапки” вместо `'` и `"`, русские буквы в именах (с, о, а, е, р, х похожи на латинские), `Console` и `Let` с большой буквы, `consle` → «может, console?». Ошибки во время работы — тоже по-русски: «переменная не объявлена», «const нельзя изменить», «используется раньше, чем объявлена»;
- уровень — файл с данными: стартовый код, эталон, что проверять (вывод, колбы), запуски с ответами на `prompt`, обязательные и запрещённые приёмы (`require`, `reject`: «ответ 12 не пиши числом — пусть посчитает Оракул»);
- для DOM-уровней (Город Механизмов) — изолированный iframe без доступа к игре, события изображает проверка.

## После запуска

- React — после JS, на том же движке (для React — Sandpack).
- Редактор уровней: «придумай уровень для одногруппников».

## Риски

- **Графика** — самая трудоёмкая часть: вся графика рисуется в коде пиксельными SVG, без внешних картинок.
- **Бесплатный Supabase засыпает после недели без активности** (каникулы) — ежедневный автоматический запрос.
- **Учебная сеть может блокировать сайты** — проверяем на этапе 0.
- **Данные несовершеннолетних** — вход по нику без почты; ник ≠ ФИО.
- **Решения уровней видны в коде сайта** — для тренажёра это допустимо: списывая, ученик обманывает только себя.

## Журнал решений

- **16.10.2026 — Лабиринт Решений и «Путь героя».** Герой идёт по подземелью по приказам: `hero.step()`, `turnLeft()`, `turnRight()`, `take()` — поднять кристалл, `zap()` — прогнать баг. Вопросы: `isWall()`, `isGem()`, `atExit()`, `look()` — что впереди, `read()` — число на табличке. Герой живёт в том же фоновом потоке, что и код: врезался в стену, наступил на баг или схватил воздух — он останавливается, а клетка вспыхивает. Больше 500 действий — «выбился из сил», это ловит бесконечные циклы. Каждый уровень проверяется в нескольких подземельях — вкладками, как гости лавки, — поэтому заучить маршрут нельзя, нужен алгоритм. Подземелье — карта строками прямо в файле уровня. Новый путь проигрывается по шагам, со следами, а итог появляется, когда герой дошёл. Звезда за краткость: в циклах уровень просит уложиться в N строк, и длинное решение засчитывается, но с одной звездой меньше. Под редактором виден счётчик строк, после `hero.` редактор подсказывает приказы, а приказ без скобок подчёркивается: `if (hero.isWall)` выполняется всегда. Три района: Развилки (Страж Иф, накидка надвое — true и false), Карусель Циклопа (Циклоп Фор) и Сердце лабиринта, где ждёт Лорд Дефолт: настоящие лабиринты проходятся правилом правой руки. Финал — Руна Решений, а злодей сбегает в Мастерскую Рецептов. В сценках Скриптории вокруг Лорда Дефолта теперь плавают undefined, NaN и null, а не Times New Roman.
- **16.10.2026 — Лавка Алхимика: Врата Скриптории целиком.** Второй район — Лавка Алхимика, наставник — Алхимик Тайпоф, а хозяйничает в ней шут NaN, подручный Лорда Дефолта. Уровни: склеивание строк, шаблоны, typeof, Number, NaN и parseInt, alert, prompt и испытание «Большой заказ». С `prompt` появились «гости лавки»: код запускается для каждого гостя с его ответами, у каждого — своя вкладка над свитком, поэтому имя или число заранее не впишешь. В испытании видно, почему ответ `prompt` нужно превращать в число: колба `count` с `'3'` стоит зелёной, а подарок `count + 1` склеивается в `'31'`. Проверка подсказывает, если `${…}` написан в обычных кавычках и если на свитке появился `NaN`. Врата Скриптории — первая земля Скриптории, которую можно спасти: Алхимик вручает Руну Типов, Лорд Дефолт сбегает в Лабиринт Решений, в летописи появляется грамота. Испытание Зала Оракула названо по образцу Каскадии — «Испытание: Кошелёк героя». В текстах уровней код с обратной кавычкой внутри берут в двойные: ``` `` `${price} монет` `` ```.
- **16.10.2026 — Скриптория: дверь, своя карта и Зал Оракула.** В углу карты Каскадии стоит дверь `<script>`. Гостю и учителю она открыта сразу, ученику — когда учитель откроет землю Скриптории или когда герой спасёт всю Каскадию; тогда земли Скриптории открываются ему по очереди, без учителя. За дверью — своя карта: дверь обратно, Врата Скриптории и три земли в тумане, вместо облаков крутятся шестерни. Если последний уровень был в другом мире, герой ждёт у двери. Земля, где остались районы в тумане, спасённой не считается — грамота за неё появится, когда земля будет построена целиком. Первый район — Зал Оракула: код студента выполняется в фоновом потоке (Web Worker) и не видит игру, зависший цикл останавливается через пару секунд. Свиток Оракула показывает вывод, полка — колбы-переменные, цвет жидкости — тип. Ошибки объясняются по-русски и до запуска, и во время работы. Приёмы уровня проверяются по «Сотворить»: «12 не пиши числом — пусть посчитает Оракул». Значение, посчитанное впустую (`gems + 3;` без `=`), подчёркивается в редакторе и называется первым среди промахов.
- **15.10.2026 — ожили все персонажи.** Лорд Дефолт теперь во весь рост, кадр 20 × 24: ухмыляется, хохочет, злится и топает, а в финале с каплей пота бежит к светящейся двери `<script>`. Настроение в сценке зависит от реплики: проигрыш его злит, остальное смешит. Наставники отвечают на каждое заклинание: успеху радуются (глаза-дуги, искры), над промахом задумываются (взгляд в сторону, капля пота). Эти кадры получаются из их портретов автоматически. Лорд Дефолт в Цитадели наоборот: твой успех его злит, промах смешит. В сценах развеваются флаги, мерцают фонари, светлячки машут крыльями, часовые и солдаты дышат; на проверку это не влияет — меняется только картинка фона, не размеры предметов.
- **15.10.2026 — покадровая анимация, проба на герое.** У игры появился герой — ученик Академии в шляпе со звездой, синем плаще и с посохом. Пять движений по 2–4 кадра 18 × 22: дышит, идёт, колдует (замах, посох вверх, вспышка, искры), радуется (прыжок) и растерянно оглядывается. Герой стоит слева от кнопки «Сотворить» и отвечает на каждое заклинание, а на карте ходит между землями. Кадры рисуются в коде, как и вся графика; анимация — лента кадров, которую CSS сдвигает на кадр за шаг. Если проба понравится — так же оживить Лорда Дефолта и наставников.
- **15.10.2026 — игра ожила.** Предметы плавно перелетают на места и перекрашиваются, а не прыгают; встал на место — вспыхивают искры; «Сотворить» раскрывает над сценой магический круг, а неудача «пшикает» и встряхивает сцену. Наставники моргают и шевелят губами, пока печатается реплика, Лорд Дефолт хохочет. В сценах мерцают звёзды, в лесу летают светлячки, в казармах — пылинки. Карта живая: плывут облака, земли покачиваются, закрытые — в тумане, тропа загорается за спасёнными землями, а маленький герой сам идёт к следующей. Звуки — 8-битные, собраны в коде; по умолчанию выключены, чтобы на уроке было тихо. Переключатель «эффекты: полные / лёгкие» — для слабых компьютеров; лёгкие включаются сами, если в системе выбрано «уменьшить движение». Проверка этого не замечает: предметы измеряются до начала перелёта.
- **15.10.2026 — Лес Селекторов и новый финал.** Ученик пишет правило целиком, а проверка сравнивает не место предмета, а его цвет: какие предметы нашёл селектор и чьё правило победило. Сообщения собираются по причинам: «Селектор не нашёл: …», «Выбраны лишние: …», «Твоё правило их нашло, но победило другое — проверь специфичность и порядок». В Древе Каскада у уровней есть чары Лорда Дефолта — стили, которые видны, но не редактируются и стоят после кода ученика: их перебивают силой селектора. `:hover` проверяется во втором зеркале «Под мышкой»; наведение там изображает метка, а не настоящий курсор, чтобы мышь над сценой не сбивала проверку. Финал игры переделан по просьбе учителя: Лорд Дефолт не исправляется, а сбегает за дверь `<script>`, и продолжение уходит в JavaScript.
- **15.10.2026 — Крепость Блоков.** Три района: Казармы (блочная модель, Леди Паддинг), Плац (display, Сержант Дисплей) и Дозорная башня (позиционирование, Капитан Абсолют). В каждом районе своя магия: свойства блочной модели, потом плюс display и visibility, потом плюс position и z-index. Проверка научилась двум новым вещам: отличать `visibility: hidden` (не виден, но место занимает) от `display: none` и понимать, кто кого заслоняет, — в центре каждого предмета смотрим, чей он сверху. Слои сравниваются, только когда предметы уже на своих местах. Где важен приём, а не только картинка (рамка, а не обивка; `margin: 0 auto`; `box-sizing`; relative, absolute, fixed), уровень требует его, но говорит об этом, когда сцена уже сложилась, — до того подсказывает, куда двигать предметы.
